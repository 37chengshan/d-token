# d-token 精简上传与重构包 (Upload Pack - 仅 7 个核心文件)

为了方便您在有文件上传数量限制（如最多 10 个文件）的平台或大模型中直接上传与重构，本目录将全套前端展示与设计规范精简为 **7 个独立文件**。

---

## 1. 包含的 7 个文件清单

| 文件名 | 角色与用途 |
| :--- | :--- |
| **`index.html`** | **全合一单文件原型 (核心)**：已将完整 HTML 结构、预编译 CSS、纯 JS 交互逻辑、SVG 图表与猫咪图标（Base64）**全部内联集成在单个文件中**。直接双击即可在任何浏览器中打开，拥有全部 8 大主页面、向导弹窗与托盘面板交互。 |
| **`styles.css`** | **独立样式表**：包含 Tailwind 与 d-token 深冷青灰设计系统所有规则。如需单独交由模型或开发修改 CSS，可直接上传此文件。 |
| **`DESIGN_SPEC.md`** | **UI/UX 设计规范**：详细定义了深色/浅色调色板、字号阶梯、卡片微拟态、内发光、状态指示灯等视觉标准。 |
| **`APP_ARCHITECTURE.md`** | **架构与产品契约**：梳理了 AppShell、8 大核心工作台、字段映射与安全边界（不可暴露公网、单 H1 原则等）。 |
| **`design-tokens.json`** | **机器可读设计 Token**：包含颜色值、圆角、字号、阴影与布局尺寸的 JSON 定义，方便快速导入 Figma 或生成代码。 |
| **`dtoken-cat-icon-96.png`** | **高清品牌 Logo 图标**：原版猫咪品牌图。 |
| **`README.md`** | 本说明文档。 |

---

## 2. 如何使用

1. **直接上传这 7 个文件**：无论是在 ChatGPT、Claude 还是第三方平台，可将本文件夹中的 7 个文件一次性全选上传；
2. **在浏览器中直接预览**：直接双击打开 `index.html` 即可完整浏览和交互；
3. **重构**：针对 `index.html` 或 `styles.css` 进行排版、视觉层次和组件结构的修改；
4. **回填**：重构完成后，将修改过的 `index.html`（或 `styles.css`）交还给我，我将自动同步回填更新到桌面端 React 源码中。
